# JARVIS UI/UX (Aurora Console)

A holographic, tactile command console for an always-on autonomous voice AI orchestrator. Features continuous voice orb telemetry, mission rail controls, multi-model execution, and interactive system views.

## Features

- **Autonomous Voice Orchestrator**: Live interactive voice orb stage with continuous audio telemetry.
- **Mission Control Deck**: Subsystem diagnostics, neural link status, and real-time mission logs.
- **TACTILE Holographic HUD**: Machined graphite chassis with frosted glass overlays and soft neumorphic relief.
- **AG-UI Architecture**: Interactive tool execution cards, streaming thought accordions, and human-in-the-loop approvals.

## Development

You need Node.js and npm (or bun):

```sh
git clone https://github.com/Jarvis-os-tech/JARVIS-UI-UX.git
cd JARVIS-UI-UX
npm install
npm run dev
```

Build for production:

```sh
npm run build
```
